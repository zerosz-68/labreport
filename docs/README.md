## 一分钟心智模型

```
labreport 只做三件事：
  1. 看懂 Word 结构（尤其合并单元格）        -> inspect
  2. 把数据/公式写进去，并告诉你写在哪        -> fill（默认只出计划）
  3. 校验与自检：数据对不对、报告全不全、能不能交 -> data check / audit / pdf

不做的三件事：
  × 不看图片（识别手写数字是 agent 的活）
  × 不编造数据（识别不出就留空并报告）
  × 不替你决定（默认只出计划，确认后才落地）
```
