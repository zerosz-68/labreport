# 实验知识卡

**通用流程在 CLI 里，实验特异性在卡里。** 换一个实验，只加一张卡，不动代码。

## 卡在哪

| 位置 | 来源 | 说明 |
|---|---|---|
| `src/labreport/cards/*.md` | 内置 | 随包分发，人人可用（目前有 `torsion-pendulum`） |
| `~/.labreport/cards/*.md` | 自建 | 你自己的实验；**同名时覆盖内置卡** |

把卡目录指到项目里（随项目走、可提交到 git）：

```bash
export LABREPORT_CARD_DIR=./cards        # Windows: $env:LABREPORT_CARD_DIR=".\cards"
```

## 常用命令

```bash
labreport card list                  # 有哪些卡、来源、摘要
labreport card show torsion-pendulum # 打印整张卡
labreport card new 用单摆测重力加速度  # 从模板建一张新卡
labreport card new 用单摆测重力加速度 -o ./cards/单摆.md
```

## 卡里写什么

模板（`card new` 生成的就是这个）分 7 节：

| 节 | 内容 | 为什么要写 |
|---|---|---|
| 1 原理与公式 | 用 LaTeX 列全公式 | 可直接喂给 `labreport omml`，也避免 agent 现推公式推错 |
| 2 标准表格结构 | 表几张、哪些列、合并关系、留空规则 | 填之前就知道"哪些格子理论上就该空着" |
| 3 量级与单位 | 记录单位、换算、量级 | **最容易出错的地方**（如 $10^{-3}$ 与 $10^{-2}$ 两张表混填） |
| 4 易错点 | 你知道的坑 | 让 agent 不重复踩 |
| 5 参考数据 | 理论值/典型值 | 可直接当 `data check` 的 `expected` |
| 6 data.json 骨架 | 本实验的字段与表达式 | 复制即用 |
| 7 map.json 提示 | 关键格子的坐标、嵌套表位置 | 少走 `inspect` 的回头路 |

## 内置卡：扭摆法测量转动惯量

`labreport card show torsion-pendulum` 能看到完整内容，包含：

- 公式：$M=-K\theta$、$J=\frac{KT^{2}}{4\pi^{2}}$、$K=\frac{4\pi^{2}J_{1}}{T_{1}^{2}-T_{0}^{2}}$、$J_{1}=\frac{1}{8}mD^{2}$、$J_{2}=\frac{1}{8}m(D_{1}^{2}+D_{2}^{2})$、$J_{3}=\frac{1}{10}mD^{2}$、平行轴 $J=J_{0}+md^{2}$；
- 四张标准表（质量与尺寸、振动周期、结果表、平行轴验证）的结构与合并关系；
- 量级陷阱：结果表是 $10^{-3}\,\mathrm{kg\cdot m^2}$，平行轴表是 $10^{-2}$；
- 参考数据（圆柱 1116.12 g / D=100.50 mm，$J_{1理}=1.4091\times10^{-3}$，$K\approx0.0348$…）可直接当 `expected`。

## 写卡的建议

1. **只写这个实验特有的事实**，通用流程别抄进卡里（那些在 `docs/`）；
2. **公式写成 LaTeX**，与报告里要出现的写法一致，能省一次转换调试；
3. **易错点要具体**："单位别混"没用，"结果表是 10⁻³、平行轴表是 10⁻²，别混"才有用；
4. **参考数据给几位有效数字就和报告一致**，否则 `data check` 会一直报差异；
5. 做完一个实验就顺手沉淀一次——下一届/下一个实验能直接用。
