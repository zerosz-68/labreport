# 标准工作流

一句话：**看照片识别数字是 agent 的活，`labreport` 负责把数据可靠地写进 Word 并证明它写对了。**

## 全流程

```
0  doctor            体检：核心依赖齐不齐
1  card show <实验>   有没有这个实验的知识卡（公式 / 表结构 / 量级易错点 / 参考数据）
2  inspect 模板       拿到物理网格：每张表几行几列、哪些是合并格、有没有嵌套表
3  读照片 → data.json 逐格确认，每个值记 source（哪张照片、哪一行）
4  data check        校验：单位归一化 / 平均值自洽 / 3σ 离群 / 公式重算比对
5  map.json          把每个值/公式落到"表N 行R 列C"或文字锚点
6  fill              ★默认只出计划（旧值→新值）→ 人确认 → 加 --apply 落地
7  audit             ★交付前必过：结构有没有坏、公式是不是原生、占位有没有残留、数据填全没
8  pdf --pages       出图自己看：中文、公式、表格不破版
9  card new          没有卡就顺手把这次的经验沉淀成一张卡
```

## 每步的产出与"谁来拍板"

| 步 | 命令 | 产出 | 谁拍板 |
|---|---|---|---|
| 0 | `doctor` | 环境报告 | 缺核心依赖就停下，先装 |
| 1 | `card show` | 实验知识（公式/表结构/易错点） | 有卡按卡，无卡按教材 |
| 2 | `inspect` | 表格物理网格、合并关系 | 填之前必做，不能凭感觉填 |
| 3 | —— | `data.json` | **agent 识别，人复核存疑格** |
| 4 | `data check` | 校验报告（error/warn/info） | **有 error 必须回看照片** |
| 5 | —— | `map.json` | 映射要看得懂：填哪里、填什么 |
| 6 | `fill` | 填写计划 + `成品.docx` | **人看计划确认后才 `--apply`** |
| 7 | `audit` | 自检结论 | **0 error 才能交** |
| 8 | `pdf --pages` | PDF + 每页 PNG | 人/agent 看图确认排版 |
| 9 | `card new` | 新的知识卡 | 可选，越用越快 |

## 两个"人工确认"点（默认行为，不是可选项）

`fill` **默认不写文件**，只打印计划：

```console
$ labreport fill 模板.docx --map map.json --data data.json
模式   : 仅出计划（默认，未写文件）
  ✓ #1  [set    ] 表2 r1c2（真实单元格锚点 r1c2）
        旧: （空）
        新: 扭摆法测量转动惯量
  ✓ #4  [formula] 表2 r6c1（真实单元格锚点 r6c1）
        旧: （空）
        新: 公式 J_{1\mathrm{理}}=\frac{1}{8}mD^{2}=0.00140914
（未写文件）确认无误后加 --apply 落地；全自动场景用 --auto。
```

`audit` 是交付门槛，输出三种级别：

- **error** → 不可交付（结构被改坏、公式是空的、正文里还有 LaTeX 残留…）
- **warn** → 需人工判断（有占位没填、某个数在成品里找不到）
- **info** → 提示（缺 source 定位、次数太少）

## 出错时的排查顺序

1. `data check` 报平均值不自洽/离群 → 回看该组 `source` 指的照片区域，逐格重认；
2. `data check` 报与预期值差太多 → 先查公式和单位，确认无误再调整 `expected`；
3. `fill` 报"超出网格" → `inspect` 看该表实际行列与合并情况，或改用 `find` 文字锚点；
4. `audit` 报 LaTeX 残留 → 公式没转成功，检查 LaTeX 里是否有不支持的命令；
5. `audit` 报数据未命中 → 漏填，或写成了别的形式（`1.4091×10⁻³` 与 `0.0014091` 工具都认）。

## 效率技巧

- **测 50 个周期**：`data.json` 里 `values` 填总时间、`scale: 0.02`（=1/50），表达式里直接用周期；
- **一批数值同源**：把共同部分写成中间目标，后面的目标引用它，避免重复抄写；
- **多个实验**：每个实验一张知识卡 + 一套 `data.json`/`map.json`，CLI 不用动。
