# labreport —— 实验报告填写（薄封装 skill）

> 本 skill 不含实现细节：所有硬活都在 `labreport` 命令里。你（agent）负责**需要理解的部分**：
> 看照片/材料、判断内容写在哪里、与用户确认。**不要手写 docx、不要自己拼 OMML 公式。**

## 0. 输入（三份，缺一不可）

| # | 材料 | 作用 | 形态 |
|---|---|---|---|
| ① | **实验报告（未填写）** | **章节提纲的唯一来源**（表内一般写着"实验报告应包括以下内容：…"）＋ 封面/表头 | `.docx` |
| ② | **课堂报告书** | **数据来源**（原始记录表格）＋ **文末附件的原件** | 手写页照片（1～2 页）＋/或整理成表格的 `.docx` |
| ③ | **实验内容设计** | 正文依据（教材/讲义里的"设计方案、目标任务、原理、步骤"） | 教材扫描页照片或 PDF |

约定目录（用户可以这样给，你自己认）：

```
某实验/
├─ 实验报告模板.docx          ← ①
├─ 课堂报告书/  img1.jpg img2.jpg …   ← ②（手写原件；也允许一份"表格整理.docx"）
├─ 教材/        img3.jpg img4.jpg …   ← ③
└─ 成品/                      ← 产出
```

**先分类再动手**：逐张看图片，判断"哪些是课堂报告书、哪些是教材、哪些是别的"，
把分类结果（文件名 → 类别 → 一句话内容）**列给用户确认**，确认后再继续。

## 1. 铁律（顺序不能变）

1. 先 `labreport doctor`；核心依赖缺失就停下，把缺什么、怎么装告诉用户，不要绕过。
2. **看照片识别手写数字是你的活**，`labreport` 不看图；但**不要自己拼 OMML**——公式交给 `fill`/`omml`。
3. 数据先落成 `data.json`，跑 `labreport data check`，**有 error 就回看照片复核，禁止猜**。
4. `fill` 默认**只出计划不写文件**：把计划给用户确认后再加 `--apply`；用户说"全自动"才用 `--auto`。
5. 交付前必须 `labreport audit … --require-attachment` 通过（退出码 0），否则不许说完成。
6. 报告里的公式**必须是 Word 原生公式**：`audit` 会检查"空公式"和"LaTeX 残留"。

## 2. 报告正文：严格按未填写报告的提纲

**章节顺序与名称以模板里的提纲为准**（不要自己发明章节，也不要改顺序）。
典型提纲如下（扭摆法）：

| 节 | 怎么写 | 依据 |
|---|---|---|
| 一、实验目的 | 简单写（3～5 条） | 模板提纲 ＋ 教材【设计方案·目标任务】 |
| 二、实验基本原理 | **公式要完整**（原生公式，可含推导），文字从简 | 教材原理部分 |
| 三、仪器及设备 | 简单写（一行罗列仪器与被测物体） | 教材 ＋ 报告书 |
| 四、实验操作步骤 | 简单写（4～6 步） | 教材步骤 ＋ 课堂报告书的操作记录 |
| **五、实验数据记录** | **把课堂报告书里的全部表格搬进来**（见下节） | 课堂报告书 |
| 六、实验数据处理过程及结果、结论 | 简单写 ＋ 关键公式与结果（原生公式） | 教材 ＋ 数据 |
| 七、问题与讨论 | 简单写（3～5 条，与本次实测数据挂钩） | 教材【交流探究】＋ 实测 |

- **除第五节外一律从简**：不要长篇大论，但公式必须完整、正确。
- 表头（实验名称/班级/学号/姓名/同组人）从**课堂报告书手写页**抄，逐一核对。
- 写正文时按"一、…／二、…"逐段追加到模板的两个正文大格里
  （常见布局：前四节一格、后三节一格；先 `inspect` 确认是哪两格）。

## 3. 第五节：把课堂报告书的表格提取出来嵌入正文

**不要手抄表格**，用提取器照抄结构：

```bash
labreport tables 课堂报告书.docx -o tables.json      # 提取全部表格（含合并关系）
labreport tables 课堂报告书.docx                     # 先看摘要：表名、行列、合并数
```

- 表名默认从表格首行（整行合并的那行）**提上来**，嵌入后会写在表格**上一行**——这正是要求；
- 空表默认跳过；要保留用 `--keep-empty`；
- 若课堂报告书只有手写照片：先自己按原表**逐格**读出来，手写 `tables.json`
  （`{name, cols, grid, merges}`，行列 1 起，被合并覆盖的格留空），**结构必须与原表一致**。

在 `map.json` 里就地插入（表格会插在**这个位置**，不是文末）：

```jsonc
{ "table": 2, "row": 6, "col": 1, "append": "五、实验数据记录" },
{ "table": 2, "row": 6, "col": 1, "insert_tables_file": "tables.json" },
{ "table": 2, "row": 6, "col": 1, "append": "六、实验数据处理过程及结果、结论" }
```

**表内公式也要是原生公式**：原表里的 `J₁=1/8mD²` 往往只是文字，在 `tables.json` 里给它加：

```jsonc
"formulas": { "2,5": "J_{1}=\\frac{1}{8}mD^{2}", "3,5": "J_{2}=\\frac{1}{8}m(D_{1}^{2}+D_{2}^{2})" }
```
（行列相对该表，1 起；`fill` 会把这些格子写成 OMML。）

## 4. 附件：课堂报告书原件放在报告最后

```bash
labreport attach 成品.docx 课堂报告书页1.jpg 课堂报告书页2.jpg --apply -o 成品.docx
```

- 默认行为：正文之后写一行 **`附件`**（不分页），随后**每张图独占一页、满宽**；
- 标签文字用 `--label` 改，不要标签用 `--label ""`；
- 附件页数应与课堂报告书实际页数一致（1～2 页），别把教材页或别的实验附进去。

## 5. 完整流程

```
0) labreport doctor
   逐张看图片 → 分类（课堂报告书 / 教材 / 其他）→ 列给用户确认
   labreport card show <实验名>           有知识卡先读卡（表格结构、量级、参考数据）
1) labreport inspect 实验报告模板.docx     拿到物理网格：正文在哪两格、表几行几列
2) 读课堂报告书 → data.json（每个值带 source）
   labreport data check data.json         有 error 就回看照片，改到 0 error
3) labreport tables 课堂报告书.docx -o tables.json     提取表格（含合并关系）
4) 写 map.json：表头 + 七节正文 + 公式 + insert_tables_file
   labreport fill 模板.docx --map map.json --data data.json            ← 先出计划
   → 把计划（每处旧值→新值、嵌入哪几张表）给用户确认
   labreport fill 模板.docx --map map.json --data data.json --apply -o 成品.docx
5) labreport attach 成品.docx 课堂报告书页*.jpg --apply -o 成品.docx    ← 文末附件
6) labreport audit 成品.docx --source 模板.docx --data data.json --require-attachment
   → 必须 0 error：章节齐备 / 公式原生 / 数据回读 / 附件在文末
7) labreport pdf 成品.docx --pages        ← 自己看图确认排版，然后交付 docx + pdf
```

## 6. 出问题怎么查

| 现象 | 处置 |
|---|---|
| `data check` 报平均值不自洽 / 离群 | 回看该组 `source` 指的照片区域，逐格重认 |
| `data check` 报与预期值相差太大 | 查公式、单位、抄录；确认无误再改 `expected` 并说明原因 |
| `fill` 报"超出网格" | `inspect` 看该表行列与合并情况，或改用锚点 `find` |
| `audit` 报缺章节 | 该节没写或标题写法与模板提纲不一致（提纲以模板为准） |
| `audit` 报 LaTeX 残留 | 公式没转成原生：检查 `formulas` / `formula` 里的 LaTeX 是否有不支持的命令 |
| `audit` 报数据未命中 | 漏填，或写成了别的形式（`1.4091×10⁻³` 与 `0.0014091` 都认） |
| `audit` 报文末没有附件 | 忘了 `attach`，或标签/图片不在文末 |
| 表格里的公式是文字 | 在 `tables.json` 的 `formulas` 里指定 LaTeX 重跑 `fill` |
| `pdf` 退出码 3 | 环境里没有 Word/LibreOffice；不影响填写与自检，把这一点告诉用户 |

## 7. 边界

- 只做"**按模板填**"：没有模板就先请用户提供；不要另建报告。
- **不编造数据**：识别不出的格子留占位并在回复里说明，绝不许猜一个数填进去。
- 用户没确认前不写文件（`fill` / `attach` 的默认行为已经保证）。
- 不认识的内容（不属于这三类材料的图）不要往报告里塞。
